# CO₂ Emissions Analysis in Malaysia

Project Overview

This project analyses the key factors associated with Malaysia's CO₂ emissions using annual data from 1981 to 2022. SPSS and Microsoft Excel were used to examine the relationship between CO₂ emissions and economic, industrial, energy, trade, and urbanisation factors.

# Objectives

Analyse the relationship between CO₂ emissions and selected economic factors.

Examine the roles of GDP, industry, energy, exports, imports, and urbanisation.

Apply regression analysis to investigate the factors associated with CO₂ emissions.

# Tools Used

SPSS — Statistical analysis and regression modelling

Microsoft Excel — Data organisation and preparation

Variables Analysed

Dependent variable: CO₂ emissions

Independent variables: GDP, industry, energy, exports, imports, and urbanisation

# Dataset

The analysis uses annual data covering the period from 1981 to 2022.

# Methodology

The data were organised and analysed using Excel and SPSS. Multiple regression analysis was applied to examine the relationship between CO₂ emissions and the selected independent variables.
